# CLIと起動方法

## 状態

V0.1方針。Webサーバーの起動入口、仕様の直接読込、`--specs`、DBパス、ポート、配布形式を定義する。

## 目的

CLIは製品の主画面ではなく、Webサーバーの起動や管理操作の入口として扱う。テストの閲覧と結果入力はブラウザを主とする。

## 起動方法

```text
testman serve --specs ./testspecs [--db ./.testman/testman.db] [--port 5000]
```

localhostでWeb画面を提供する。画面表示時には仕様ファイルを原本として直接読み込み、SQLiteへ仕様本文をimportしない。

`--specs`には、`.md`ファイルまたはディレクトリの絶対パス・相対パスを指定できる。相対パスは起動時のカレントディレクトリを基準とする。ファイル指定時はその1ファイルだけを読み、ディレクトリ指定時は配下の`.md`を再帰的に読む。シンボリックリンクおよびWindowsのジャンクションは探索しない。

指定パスが存在しない場合、または指定ディレクトリ配下に対象`.md`が1件もない場合は、ターミナルへエラーを表示してWebサーバーを起動しない。対象ファイルを確定した後に個別ファイルの読込・文字コード・解析エラーが発生した場合はサーバーを起動し、Web画面上部へ診断を表示する。正常に解析できたファイルとtitleは表示を継続する。

正常に起動・終了した場合の終了コードは`0`とする。引数不正、指定パスの不存在、対象`.md`なしなど、Webサーバーを起動できない場合の終了コードは`1`とする。

`--specs`は必須とする。`--db`と`--port`は任意とし、既定値はそれぞれ `./.testman/testman.db` と `5000` とする。`--db`の相対パスは起動時のカレントディレクトリを基準とする。`--port`には利用可能な1から65535までの整数を指定できる。ポートを変更しても待受アドレスはlocalhostに限定する。

V0.1ではユーザー向け設定ファイルを設けず、上記の設定はコマンドライン引数だけで指定する。そのため、設定ファイルとの優先順位は定義しない。

## V0.1方針

V0.1では `serve` でlocalhostにWeb画面を提供し、画面表示時に現在の仕様ファイルを直接読み込む。仕様本文をSQLiteへimportするコマンドは設けない。

## 配布

- Windows x64向けの自己完結型publishをzipアーカイブとして配布し、利用PCへ.NETランタイムの事前インストールを要求しない。
- 配布物に含めるサテライトリソースの言語は英語 (`en`)、日本語 (`ja`)、簡体字中国語 (`zh-CN`) に限定する。どの言語をアプリケーションの既定表示にするかは、この配布物の制限では指定しない。
- 繁体字中国語 (`zh-Hant`、`zh-TW`、`zh-HK`など) およびその他の言語のサテライトリソースを配布物へ含めない。
